# DATASHIELD
Privacy-Preserving Distributed Intelligence Platform (AARAMBH 2026, PS09)

Three simulated banks train a fraud-detection model together using federated
learning, without sharing raw transactions. The platform simulates a malicious
bank, detects its poisoned updates, and demonstrates privacy protection.

Run: pip install numpy pandas scikit-learn streamlit plotly, put creditcard.csv
(Kaggle, ULB) in the data folder, then run: streamlit run app.py
